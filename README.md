# Turbos IH — sitio web

Página de una sola sección (`index.html`) para Turbos IH, especialistas en
turbocargadores diésel y gasolina. Todo el diseño, textos y botones de
WhatsApp están dentro de ese único archivo — no necesitas ningún programa
para editarla ni publicarla.

## Cómo publicarla (elige una opción, ambas son gratis)

**Opción A — Vercel (arrastrar y soltar, la más simple):**
1. Entra a [vercel.com](https://vercel.com) y crea una cuenta gratis.
2. En el panel, busca "Add New… → Project" y la opción de subir una carpeta
   (drag & drop / "Deploy without Git").
3. Arrastra este archivo `index.html`.
4. Vercel te da un enlace tipo `turbos-ih.vercel.app` en segundos.

**Opción B — Netlify Drop (igual de simple):**
1. Entra a [app.netlify.com/drop](https://app.netlify.com/drop).
2. Arrastra el archivo `index.html` a la página.
3. Te da un enlace público al instante; luego puedes ponerle tu propio
   dominio desde "Domain settings".

## Cómo editar los textos o el número de WhatsApp

Abre `index.html` con cualquier editor de texto (o pídeme a mí que lo haga).
Los números de WhatsApp aparecen como enlaces `https://wa.me/52...` — para
cambiar el número, solo se cambian los dígitos después de `wa.me/`.

## Estructura del contenido

La página sigue el documento de contenido original: portada, por qué comprar
con Turbos IH, diagnóstico previo a la instalación, motivos para elegir
Turbos IH, aplicaciones (HE561, HE451, HX55, K27, HT3B), cotizador por
WhatsApp, sección para talleres y mecánicos, cierre, y pie de página con
ambos números de contacto etiquetados.

## Nota sobre las imágenes

Esta primera versión usa un diagrama técnico animado del turbocargador
(dibujado en el propio código, sin depender de fotos) porque las fotos e
imágenes mencionadas en el documento de contenido no llegaron adjuntas.
Si me las envías, las incorporo a la portada, la sección de "por qué
comprar" y la de aplicaciones tal como indica el documento original.
